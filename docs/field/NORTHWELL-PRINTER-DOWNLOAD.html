SYSADMINSUITE / APPROVED NORTHWELL SHARED-PRINTER WORKFLOW

Printer mapping, with a standard-user recovery path.

One download. Two technician CMD launchers. No copying terminal commands from an agent.

Deployment notice: the new standard-user fallback is implemented but not yet field-certified. Do not label a printer READY until the intended user sees the queue after login.

1. Download the current repository package

On an approved admin workstation with access to the trusted repository, obtain the current source package. Your organization's approved, checksum-verified field release takes precedence. The moving-main ZIP is source distribution, not a signed/approved enterprise installer.

Download SysAdminSuite ZIP Release packages & checksums

Extract the complete ZIP before opening a CMD. A standalone CMD without sibling dependencies must refuse to run. If Smart App Control or security policy blocks the package, use your organization's approved signed deployment route; do not disable protections.

2. Map approved shared printers

  1. Connect to approved Northwell hardwire, WAB or authenticated VPN.
  2. Open Map-NorthwellPrinter.cmd for one or several targets, or Map-NorthwellPrinters-FromFile.cmd for an approved assignment batch.
  3. Review the exact host and shared queue plan, then approve it. Preserve the run evidence.
  4. Log out of the privileged technician account and log into an approved standard-user session to verify actual printer visibility.

3. If the standard user cannot see the queue

  1. Open Recover-NorthwellPrinter-Session.cmd from the current trusted runtime/source folder after canonical SYSTEM/HKLM mapping proof exists.
  2. Select 1: durable per-user logon task for future users, or 2: one-shot Common Startup as the bounded emergency bridge.
  3. Enter the approved workstation hostname, inspect the read-only preflight and type APPLY only after observing the failure. No guessed printer/IP mapping is permitted.
  4. Log in as the standard user and confirm the queue is present. User receipts are written to %LOCALAPPDATA%\SysAdminSuite\Printer\latest-printer-session.json.
  5. One-shot cleanup is performed by an owned privileged scheduled task only after proof; if it cannot verify/clean, recovery is incomplete. One-shot alone does not guarantee future users.

4. Inspect, repair or retire

Use the same recovery CMD's Status or Retire choice. The tool removes only its owned helper/task artifacts after explicit confirmation. Preserve canonical mapping evidence and do not repeat failing mapping blindly.

No website can silently execute a downloaded CMD in a browser. Windows/UAC and your organization's policy remain the execution gate. Support and governing source: deployment issue #548.

5. Field error? Prepare a private report for your agent

Open Report-NorthwellPrinter-Issue.cmd from the extracted, trusted SysAdminSuite field package. Choose the symptom. It creates a read-only offline report, opens a safe handoff, and never publishes raw client evidence or changes a printer. Share only the sanitized handoff with your approved agent.

The agent's canonical next action is described in Printer Field Incident Agent Runbook. An agent does not gain authorization to perform live workstation changes merely by receiving a report.
