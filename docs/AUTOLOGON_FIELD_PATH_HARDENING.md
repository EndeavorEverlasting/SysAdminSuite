# AutoLogon field path hardening

The AutoLogon field transaction must remain usable from long OneDrive/backup repository locations. Live field evidence is therefore rooted under a bounded machine-local path rather than recursively beneath the repository checkout. The repository remains the code/configuration authority; generated live evidence remains local and untracked.

The outer field transaction owns protected-network admission. Operator launchers must not add a second, divergent network-profile test before that canonical gate.
